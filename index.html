About this dashboard

This dashboard provides an interactive interface for examining Sentinel-2 satellite imagery and spectral indicators across administrative areas in The Gambia. Users can select a Region, LGA, District, Ward or Enumeration Area and display the corresponding satellite image and boundary features.

NDVI: vegetation greenness and density indicator.
NDMI: vegetation moisture indicator.
NDBI: built-up surface indicator.
NDWI: water-related spectral indicator.
NDRE: red-edge vegetation indicator.
NBR: burn-related spectral indicator.

Methodology and limitations

Satellite imagery is requested from the Esri Sentinel-2 ImageServer using its published raster functions. The selected administrative features are retrieved from the GitHub JSON file. In selected-area mode, a map overlay hides imagery outside the selected polygons.

The map overlay is a display mask; it does not perform a raster clip or calculate zonal statistics. The displayed image is not a direct measurement of land-surface temperature. Image availability and appearance depend on the satellite service, image dates, cloud cover and selected raster function.

Data sources
